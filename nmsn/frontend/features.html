Core Features

Built on proven infrastructure with enterprise-grade reliability and security.

Instant Settlement Engine

Our proprietary settlement engine processes metal-to-INR conversions in under 2 seconds using advanced smart contracts and real-time pricing feeds.

  • Sub-2 second settlement times
  • Real-time price calculations
  • Automatic BINR minting/burning
  • Fault-tolerant processing

Regulatory Compliance Suite

Comprehensive compliance engine that automatically handles RBI, SEBI, and FIU requirements with built-in AML/KYC verification and suspicious activity monitoring.

  • RBI guidelines compliance
  • SEBI reporting automation
  • FIU transaction monitoring
  • Suspicious activity alerts

Multi-Metal Token Support

Accept payments in Gold (BGT), Silver (BST), Platinum (BPT), and Metal Basket Tokens (MBT) with automatic portfolio rebalancing and price hedging.

  • BGT Gold token support
  • BST Silver token support
  • BPT Platinum token support
  • MBT basket rebalancing

Vault Network Integration

Direct integration with certified vault providers including MMTC-PAMP, Augmont, SafeGold, and others for real-time asset verification and physical settlement.

  • MMTC-PAMP integration
  • Augmont connectivity
  • SafeGold API integration
  • Physical delivery support

Mobile-First Experience

React Native mobile app with QR code payments, biometric authentication, wallet management, and seamless user onboarding experience.

  • QR code payment scanning
  • Biometric authentication
  • Wallet management
  • Transaction history

Real-Time Analytics Dashboard

Comprehensive merchant dashboard with transaction analytics, settlement reports, GST-ready invoicing, and predictive insights.

  • Real-time transaction monitoring
  • GST-ready invoice generation
  • Settlement reconciliation
  • Business intelligence reports
